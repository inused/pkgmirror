# pkgmirror 删除设计

`delete` 子命令和浏览页通过 `POST /api/delete` 删除镜像资源。执行前可预览文件清单；包和模块支持依赖级联，安装包支持单文件或版本组删除。

## 1. 删除单位

| 类型 | 目标 | 直接删除 | `--deps` |
| --- | --- | --- | --- |
| pypi / npm | 包名 | 整包全部版本 | 连同未被其他包引用的传递依赖 |
| gomod | 模块路径 | 整模块全部版本 | 连同未被其他模块引用的传递依赖 |
| python | 归档文件名或版本，如 `3.12.15`、`3.12` | 单归档及其校验文件，或匹配版本的全部文件 | 文件名目标扩展为所属版本组；版本目标不接受 |
| node | 归档文件名或版本，如 `v22.14.0`、`v22` | 单归档，或匹配版本的全部文件 | 文件名目标扩展为所属版本组；版本目标不接受 |
| golang | 归档文件名或版本，如 `1.23.4`、`1.23` | 单归档及其校验文件，或匹配版本的全部文件 | 文件名目标扩展为所属版本组；版本目标不接受 |

Python 和 Go 安装包的同名 `.sha256` 文件随主文件删除。Node 的 `SHASUMS256.txt` 在同版本归档间共享，仅在该版本归档全部删除后清理；它不能单独作为删除目标，内容按官方原样保存。

## 2. 命令行

```
pkgmirror delete <pypi|npm|gomod> <包名|模块路径> [--deps] [--yes]
                           [--server URL] [--user NAME] [--pass PASS]
pkgmirror delete <python|node|golang> <文件名|版本> [--deps] [--yes]
                           [--server URL] [--user NAME] [--pass PASS]
```

客户端先发送 dry-run 请求，打印目标与级联清单的名称、文件数和大小，再等待 `y/N` 确认。确认后重新请求执行，打印删除文件数与释放空间。`-y/--yes` 跳过交互确认。

服务端地址支持 URL 内嵌凭据，也可用 `--user/--pass` 指定。删除请求禁用 HTTP 代理。目标不存在时返回 404，客户端保留服务端错误文本。

## 3. 接口

接口经过 Basic auth 中间件，只接受 POST，防止链接预取或爬虫触发删除。

### JSON 请求与响应

请求字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `type` | string | 六种镜像类型之一 |
| `name` | string | 包名、模块路径、归档文件名或版本 |
| `deps` | bool | 是否级联；默认 false |
| `dryRun` | bool | true 只返回清单；默认 false，执行删除 |

响应包含：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `status` | string | `preview` 表示预览，`ok` 表示执行成功 |
| `targets` | 单元数组 | 指定目标的删除清单 |
| `cascades` | 单元数组 | 级联清单；为空时省略 |
| `count` | int | 目标与级联文件总数，包含伴随校验文件 |
| `total` | int64 | 文件总字节数 |

每个单元含 `name`、`files` 和 `size`；每个文件含相对数据根目录的 `path` 和字节数 `size`。

### 网页表单

表单使用 `application/x-www-form-urlencoded`：

- `type`、`name` 指定目标；
- `dryRun=1` 渲染预览页；
- 执行时 `deps=1` 级联删除，否则只删除目标。

执行成功后 303 重定向至对应类型的列表页，`msg` 参数显示结果。返回地址由服务端固定映射，防止 Referer 引发开放重定向或跳回只接受 POST 的接口。

### 校验

PyPI 包名按 PEP 503 规范化并校验；npm 包名、Go 模块路径分别按各自白名单校验。安装包文件名和版本按对应格式校验。非法目标返回 400，不存在的目标返回 404，非 POST 请求返回 405。安装包按版本删除时携带 `deps=true` 返回 400。

## 4. 依赖级联

依赖图在请求内从镜像文件推导：

- PyPI：合并各发行文件中 wheel `METADATA`、sdist `PKG-INFO` 的 `Requires-Dist`，包含 marker 和 extras 条目。
- npm：读取 `packument.json`，仅收集已镜像 tarball 对应版本的 `dependencies` 与 `optionalDependencies`。
- Go 模块：合并 `@v/*.mod` 中的 `require` 声明。

图仅包含指向镜像内已有包或模块的边。读取、解析失败的元数据被跳过，可能遗漏依赖引用；执行前需核对预览清单。

级联集合按反向可达计算：

```
victims = closure(target) − reachable(roots)
closure(target) = target 的传递依赖，不含 target
roots = 全部包 − {target} − closure(target)
reachable(roots) = roots 沿依赖边可达的包
```

被幸存包引用的依赖保留；只被删除目标引用的依赖可级联删除，包含其中的依赖环。显式指定的目标即使被其他包依赖也会删除。

## 5. 文件删除与并发

目录目标收集文件清单后调用 `os.RemoveAll`，文件目标逐个调用 `os.Remove`。删除后清理空的 npm scope 目录、Go 模块路径父目录和 Python 构建标签目录。

上传、下载与删除之间不加锁。并发删除可能使下载失败，并发上传可能重新写入文件；预览和执行分别扫描，清单也可能在两次请求间变化。

成功执行记录审计日志：

```
已删除 ip=192.168.1.10 npm lodash 文件=2 释放=1.2M 级联=无
```

## 6. 页面

六类列表的行尾删除按钮提交 `dryRun=1`，进入预览页。标题旁的取消按钮返回列表；每个清单区块有对应的执行表单：

- 目标区块：`直接删除（N 个文件）`。
- 级联区块：显示依赖或版本组其余文件，`级联删除（K 个文件）` 中 K 为目标和级联的文件总数。

没有级联内容时隐藏级联区块。执行使用标准表单提交，成功后返回类型列表并显示结果。Node 校验清单行没有独立删除按钮。

## 7. 实现与验证

| 文件 | 职责 |
| --- | --- |
| `internal/pypi/pypi.go` | 从 wheel、sdist 提取依赖包名 |
| `internal/npm/npm.go` | 按已镜像 tarball 提取 packument 依赖 |
| `internal/server/delete.go` | 请求校验、清单、依赖图、级联计算、删除与审计日志 |
| `internal/server/pages.go` | 列表入口和预览表单 |
| `internal/client/delete.go` | CLI 预览、确认与执行 |
| `main.go` | 命令分发与帮助 |

`internal/server/delete_test.go` 覆盖单删、级联、公共依赖保留、预览、安装包文件与版本组、空目录清理、错误状态和表单返回；客户端与协议包测试覆盖删除请求及依赖元数据解析。运行 `go test ./...` 验证。
