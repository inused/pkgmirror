# pkgmirror 页面与日志设计

页面按 Python、Node.js、Go 分组，六类镜像列表支持浏览器端模糊过滤。搜索库 uFuzzy 随二进制内嵌，离线可用。服务端记录文件下载、资源缺失、上传和删除日志。

## 1. 导航与排序

导航顺序：

```
首页 | Python ▸ 安装包 · PyPI 包 | Node.js ▸ 安装包 · npm 包 | Go ▸ 安装包 · Go 模块 | 上传
```

组名使用灰色小字，组间以竖线分隔。导航脚本按路径最长前缀匹配高亮当前入口，首页只匹配 `/`。

页面、命令帮助与文档同时出现多种语言时，按 Python → Node.js → Go 排序：

- 导航、首页统计、浏览路由表、download 类型枚举：组内安装包在前、包仓库在后。
- 首页接入配置、协议路由表、README 接入示例：组内包仓库在前、安装包在后。
- 上传表单以 PyPI wheel 上传为首项；delete 帮助按包名、版本号两类目标分别列出。

## 2. 列表搜索

### 数据与匹配

Python、PyPI、Node、npm、Go 安装包和 Go 模块列表均全量渲染，浏览器直接过滤已显示的行。整行文本参与匹配，可按包名、版本、平台或文件名搜索。

搜索使用内嵌 uFuzzy 的 `intraMode:1` 模式，支持单字符插入、删除或替换的容错匹配。脚本依次调用 `filter`、`info`、`sort`，按相关度重排行；未命中的行隐藏，清空输入后恢复原始行序。计数显示“命中 N 项”或“无匹配项”。

### 资源与降级

- 库文件位于 `internal/server/static/ufuzzy.min.js`，通过 `go:embed` 嵌入，`/static/ufuzzy.min.js` 直接输出其内容。
- 搜索输入框与计数由列表模板输出，共享脚本位于 `pages.go` 的 `filterScript`。
- uFuzzy 未加载时退回子串匹配；JavaScript 不可用时显示完整列表。

## 3. 日志

### 记录范围

| 事件 | 触发位置 | 格式示例 |
| --- | --- | --- |
| 下载 | 六类镜像的文件下载处理器，通过路径与文件存在性检查后 | `下载 ip=192.168.1.10 GET /mirror/pypi/requests/requests-2.34.2-py3-none-any.whl 200 356.2K` |
| 缺失 | 文件或协议资源缺失，以及返回 404 的路径校验分支 | `缺失 ip=192.168.1.10 GET /mirror/npm/lodash/-/lodash-4.17.21.tgz 404 0B` |
| 已接收 | `storeUpload` 写入文件成功 | `已接收 ip=192.168.1.10 npm/lodash/lodash-4.17.21.tgz (sha256=abc123)` |
| 已删除 | 非预览删除请求执行成功 | `已删除 ip=192.168.1.10 npm lodash 文件=2 释放=1.2M 级联=无` |

浏览页、simple 索引以及成功的 packument、`@v/list`、`@latest` 请求不记录访问日志。npm packument 与 Go 模块资源缺失时记录“缺失”。下载日志在调用 `http.ServeFile` 前写入，表示文件通过检查，不表示客户端已收完内容。

### 来源 IP

`clientIP(r)` 依次取：

1. `X-Forwarded-For` 首段；
2. `X-Real-IP`；
3. `RemoteAddr` 主机部分。

转发头可由客户端伪造。日志 IP 用于排障，不参与访问控制；使用反向代理时应由可信代理设置这些头。

### 大小字段

`humanSize` 将字节数格式化为 `512B`、`356.2K` 等，缺失日志记 `0B`。日志字段顺序固定，可按事件、IP 和路径检索。

### 客户端 URL 脱敏

客户端日志和命令退出错误中的 URL 隐藏用户信息、敏感查询值和片段，保留
主机、路径及普通查询条件。实际请求使用原地址，认证与下载不受展示文字影响。

## 4. 验证

`internal/server/server_test.go` 覆盖来源 IP 回退、下载与缺失日志、上传日志、导航顺序、搜索资源引用和内嵌库输出；`delete_test.go` 覆盖删除预览与执行。

运行 `go test ./...` 检查服务端行为。浏览器检查包括导航高亮、搜索排序、清空恢复和无匹配提示。
