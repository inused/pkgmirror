# pkgmirror 设计

pkgmirror 为离线环境提供 Python、Node.js、Go 安装包及 PyPI、npm、Go 模块镜像。单二进制包含服务端、下载、上传和删除命令，数据存放在文件目录中。

项目使用 Go 1.20.7 构建以支持 Windows 7；TOML 配置由 BurntSushi/toml 解析，命令行参数由 pflag 解析。

## 1. 使用流程

联网机器下载所需文件和清单，经 U 盘等介质带入内网后上传。服务端通过各语言的原生镜像协议分发，客户端接入方式见 [使用指南](使用指南.md)。

网页提供文件浏览、搜索、手工上传和删除预览。服务端支持 Basic auth，用户表为空时允许匿名访问。

本文说明总体架构及 Python/PyPI 实现。其他类型见 [npm设计](npm设计.md)、[node设计](node设计.md)、[golang设计](golang设计.md)，删除流程见 [删除设计](删除设计.md)。

## 2. 总体架构

```
外网机                                内网
pkgmirror download                     pkgmirror server（常驻，监听 :19999）
  ├─ uv pip compile --universal  →    ├─ /mirror/simple/{name}/ PEP 503（动态扫描 pypi/）
  │  依赖解析（需外网机装 uv）        ├─ /mirror/pypi/...     PyPI 包文件下载
  ├─ 从 PyPI simple API 下载          ├─ /mirror/python/{tag}/{file} 安装包下载
  ├─ 从 uv 仓库元数据下载             ├─ /api/upload          上传接口（客户端+网页共用）
  │  CPython 安装包                   └─ / /browse/* /upload  人用页面
  └─ 产出文件目录与 manifest.json
        │ U 盘拷贝
        ▼
内网任意机 pkgmirror upload <目录> ──POST──> /api/upload
```

## 3. 命令行

```
pkgmirror server  [--config server.toml]
pkgmirror download python <版本>... [--platform linux] [--arch x86_64] [--all]
                            [--github-prefix URL] [--proxy URL] [-o 目录]
pkgmirror download pypi --python 3.11[,3.12] <包名[==版本]>... [-r FILE]
                       [--platform linux,windows] [--arch x86_64,aarch64]
                       [--index-url URL] [--proxy URL] [-o 目录]
pkgmirror upload <下载产出目录> --server http://host:19999 [--user u --pass p]
```

`download` 支持 python、pypi、node、npm、golang、gomod 六种类型；`delete` 按类型删除资源。各命令参数见 `pkgmirror <命令> -h`。

## 4. 服务端

### 4.1 存储布局（root 目录）

```
data/
├── pypi/{规范包名}/{name}-{version}-*.whl|.tar.gz|.zip
├── python/{构建tag}/cpython-...-install_only*.tar.gz
├── npm/、node/、golang/、gomod/（各镜像类型平铺，见对应设计文档）
└── （伴随 {文件名}.sha256 缓存，十六进制小写，simple 页面生成时按需计算）
```

- 规范包名按 PEP 503：小写、`[-_.]+` 连续折叠为 `-`；
- 构建标签为 8 位日期数字；
- simple 页面每次请求实时扫描目录，文件哈希读取同名 `.sha256` 缓存。

### 4.2 路由（全部经 Basic auth 中间件）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 首页：统计+导航 |
| GET | `/mirror/simple/` | PEP 503 根索引（全部包名 anchor） |
| GET | `/mirror/simple/{name}/` | 包文件页，href=`/mirror/pypi/{name}/{file}#sha256=...` |
| GET | `/mirror/pypi/{name}/{file}` | PyPI 包文件下载 |
| GET | `/mirror/python/{tag}/{file}` | 安装包下载；404 提示在外网执行 `download python <版本>` 补同步 |
| GET | `/browse/pypi/`、`/browse/pypi/{name}/` | 人用浏览页（包列表/文件列表） |
| GET | `/upload` | 上传表单页 |
| POST | `/api/upload` | 上传接口，multipart 表单 |

完整路由见 [路由设计](路由设计.md)。`/browse/*` 提供浏览页面，`/mirror/*` 提供协议响应与文件。

simple HTML 为 PEP 503 原生格式（`text/html`），pip/uv 均直接支持。

### 4.3 上传接口（客户端与网页共用）

multipart 表单字段：

| 字段 | 说明 |
| --- | --- |
| `type` | `pypi`、`python`、`npm`、`node`、`golang` 或 `gomod` |
| `name` | PyPI/npm 包名或 Go 模块路径；npm、gomod 必填，PyPI 可留空由文件名解析 |
| `tag` | python 构建标签（8 位数字）或 node 版本号（vX.Y.Z） |
| `sha256` | 调用方提供的期望哈希，服务端落盘前校验（网页上传可留空） |
| `file` | 文件本体 |

处理规则：

- 文件名仅允许 `[A-Za-z0-9._+-]`，拒绝路径分隔符与 `..`；
- type=pypi 落盘 `pypi/{norm(name)}/{filename}`；name 缺失时从文件名解析（首段 `-` 前，规范化），解析失败返回 400；
- type=python 落盘 `python/{tag}/{filename}`；
- 目标已存在：sha256 一致返回 `{"status":"skipped"}`（幂等），不一致返回 409；
- 先写 `.part` 临时文件再 rename，写入成功同步写 `.sha256` 缓存；
- 响应 `{"status":"ok|skipped","path":"..."}`。

### 4.4 认证

- `server.toml` 中 `[users]` 表；空表允许匿名浏览、下载、上传和删除，启动日志显示认证状态；
- `Authorization: Basic` 校验，密码比较用恒定时间比较；
- 401 响应带 `WWW-Authenticate: Basic realm="pkgmirror"`；
- 内网用户侧配置示例：`UV_INDEX_URL=http://user:pass@host:19999/mirror/simple`、`UV_PYTHON_INSTALL_MIRROR=http://user:pass@host:19999/mirror/python`（pip 同理，凭据嵌入 URL）。

### 4.5 配置（server.toml）

```toml
# 监听地址
listen = ":19999"
# 数据根目录，每类镜像占一个顶层子目录
root = "./data"

# Basic auth 用户表；留空则不启用认证
# 启动前替换占位口令
[users]
admin = "CHANGE_ME_BEFORE_STARTING"
```

`--config` 指定路径；缺省时依次查找当前目录、二进制目录下的 `server.toml`。文件不存在时按默认值启动并提示。相对 `root` 基于配置文件目录解析，无配置文件时基于二进制目录。

## 5. 客户端 download

`download python` 使用版本位置参数；`download pypi` 使用包名或 `-r` 需求文件，`--python` 必填，控制依赖解析下限和 wheel 过滤。pflag 支持选项与位置参数交错排列。

### 5.1 源与代理选择

命令行参数 > 客户端配置文件（`--config` 指定，默认探测当前目录与二进制目录下的 `client.toml`，
模板见 `resources/client.example.toml`）> 环境变量 > 内置默认，各配置项独立生效：

| 配置项 | 优先级链 | 默认 |
| --- | --- | --- |
| PyPI 索引 | `--index-url` > 配置文件 `index-url` > `UV_INDEX_URL` > `PIP_INDEX_URL` > pip.conf `[global] index-url` | 官方源 |
| GitHub 反代 | `--github-prefix` > 配置文件 `github-prefix` > `GITHUB_PREFIX` | 直连 |
| HTTP 代理 | `--proxy` > 配置文件 `proxy` > `HTTP_PROXY`/`HTTPS_PROXY`（含小写，Go 标准行为） | 直连 |

代理实现：显式代理通过 `http.ProxyURL` 固定到 Transport；未配置时沿用
`http.ProxyFromEnvironment` 读取代理环境变量。
upload 子命令的目标是内网地址，显式禁用代理，避免外网代理环境变量劫持内网请求。

### 5.2 依赖解析（调用外网机的 uv）

- 全部输入为 `name==version` 时直接下载指定版本，传递依赖须写入清单；
- 输入含裸包名或版本范围时调用 uv，未安装则报错并给出安装指引；
- 将 `-r` 文件与命令行包名合并为临时 requirements.in；
- 执行 `uv pip compile --universal --no-header --index-url {源} -p {下限} {in} -o {lock}`；
- `--python` 指定的多个版本取最小 minor 作为 `-p` 下限；
- universal 锁按 Python 版本分叉选包，支持同一包在不同 Python 版本使用不同发行版；
- 解析锁文件仅需非缩进 `name==version` 行，缩进注释行忽略；
- `download pypi` 的 `--python` 必填（uv 解析下限 + wheel 过滤）；包名带 `==版本`
  时锁定版本，裸包名经 uv universal 解析取兼容目标 Python 区间的最新版
  （多版本目标按 fork-strategy 自动分叉）；

### 5.3 PyPI 文件下载

- 对锁中每个 `name==version`：请求 `{源}/simple/{norm}/`（`Accept: application/vnd.pypi.simple.v1+json`，回退 HTML）；
- wheel 按目标 Python 版本（py3 通用 / cpN 精确 / abi3 向后兼容）与 `--platform`、`--arch`
  过滤平台标签；纯 Python wheel（any）与 sdist 不受过滤、始终保留；
- yanked 按 PEP 592/691 处理：JSON `yanked` 为布尔或撤回原因字符串，HTML 以
  `data-yanked` 属性存在为准（属性值即原因）；有非撤回文件匹配锁定版本时忽略撤回文件，
  撤回文件为锁定版本唯一匹配时仍下载并打警告（对齐 pip 精确锁定 `==` 的行为）；
- sha256 以 simple API 提供值为准，落盘 `{out}/pypi/{norm}/{filename}`。

### 5.4 CPython 安装包下载

- 元数据：`https://raw.githubusercontent.com/astral-sh/uv/main/crates/uv-python-managed/download-metadata.json`（包含各版本与平台的下载地址、文件名和哈希）；
- 过滤条件：`name == "cpython"`、非 prerelease、无构建变体（排除 freethreaded/debug）；
- 版本参数 `3.12` 取该 minor 最新 patch；`3.12.4` 精确匹配；`--all` 下载该系列全部历史 patch；
- `--platform linux,windows` 按 `os` 过滤、`--arch x86_64,aarch64` 按 `arch.family`
  过滤（amd64/arm64 为别名），默认全平台全架构；
- 从条目 `url`（GitHub release 直链）下载，sha256 校验，落盘 `{out}/python/{build}/{filename}`。

### 5.5 下载产出目录

```
downloads/            # 默认固定目录；-o 可换
├── manifest.json
├── pypi/{norm}/{filename}
└── python/{tag}/{filename}
```

manifest.json：`{"version":1,"generator":"pkgmirror 版本","created":RFC3339,"files":[{"type","name/tag","filename","path","sha256","size"}]}`。
默认目录固定为 `downloads/`，重复下载时清单与已有条目**增量合并**（本次优先、
旧条目中磁盘仍存在的保留、文件已删除的剔除），不整体覆盖。下载失败即中止。

## 6. 客户端 upload

- 读 `{目录}/manifest.json`，逐条向 `{server}/api/upload` POST（Basic auth，凭据取 `--user/--pass` 或 URL 内嵌）；
- 服务端跳过已存在同哈希文件，幂等可重复执行；
- 结束打印汇总：新增 / 跳过 / 失败明细，失败非零退出码。

## 7. 验证

- 单元测试：PEP 503 规范化、锁文件解析、wheel/sdist 文件名解析、simple JSON/HTML 双格式解析、元数据过滤（最新 patch/精确/变体排除/平台过滤）、上传路径校验（防穿越）、auth 中间件（含 401/凭据错误/恒定时间路径）；
- 集成冒烟：下载一个小包和一个平台受限的 Python 安装包，启动服务端后上传，通过 `/mirror/simple/{name}/` 和 `/mirror/python/{tag}/{file}` 检查文件，再次上传检查幂等。
- 构建：`go build ./...`；跨平台产物通过 `scripts/build.sh` 或 `scripts/build.bat` 构建。

## 8. 构建与产物

`scripts/build.sh`（Linux/macOS）与 `scripts/build.bat`（Windows）交叉编译四个平台
产物到 `dist/`，附带两份示例配置、README、`LICENSE` 和 `THIRD_PARTY_NOTICES`：

- pkgmirror-windows-amd64.exe（使用 Go 1.20.7 构建，支持 Windows 7）
- pkgmirror-linux-amd64 / pkgmirror-linux-arm64（CGO 禁用，静态链接）
- pkgmirror-darwin-arm64

`scripts/release` 使用 Go 标准库按固定文件清单生成 `dist/release/` 下的四个
平台 ZIP 和 `SHA256SUMS`，供 GitHub Release 分发。

## 9. 风险与约束

1. **内网 uv 版本不宜过旧**：每个 minor 的新 patch 只被较新 uv 的内置元数据认识；旧 uv 请求新文件会 404。服务端 `/mirror/python/` 的 404 提示页引导补同步。内网统一 uv 版本即可规避。
2. **同名不同内容**：上传 sha256 不一致返回 409，需人工删除旧文件，不自动覆盖。
3. **HTTP 明文**：服务端使用 HTTP，Basic auth 凭据随请求明文传输；嵌入命令的凭据也可能记录在 shell 历史中。
